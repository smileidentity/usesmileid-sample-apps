# Plans and open work

This folder records the work that is not done yet, and the reasoning behind changes still being made.

- [`backlog.md`](backlog.md) lists every known gap in the four apps: what is wrong or missing, and what
  done looks like. Start there if you want to contribute.
- A plan for a larger change sits beside it as its own file, and is deleted by the pull request that
  finishes the work. The reasoning it recorded moves into the `docs/` page it belongs to, so nothing is
  lost when the plan goes.

Everything here is written for a public reader from its first line: no internal names, no credentials,
nothing that only makes sense to someone who was in the room.

Some older documents in this folder predate that rule. They are being folded into the `docs/` pages and
deleted one by one, and they stay only until their page exists.
