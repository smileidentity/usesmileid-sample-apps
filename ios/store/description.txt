UseSmileID Sample is the reference app for the Smile ID mobile SDKs. It runs the same verification flows a Smile ID integration ships, so each product can be seen end to end before any code is written.

Verification runs use the Smile ID sandbox unless a linked session token specifies another environment.

PRODUCTS

SmartSelfie™ Enrollment captures a selfie and a set of liveness images to enroll an individual's biometrics. Smile ID confirms the images are of a live person and creates an enrolled reference image for the user, which SmartSelfie™ Authentication later verifies against. It is suitable for onboarding new users and establishing a biometric profile.

SmartSelfie™ Authentication verifies a returning user's identity by comparing a newly captured selfie against the image enrolled for that user. It is suitable for re-verifying returning users: confirming identity at login, authorizing high-value transactions, account recovery, and step-up authentication.

Document Verification confirms the authenticity of an identity document and that it belongs to the person presenting it. Smile ID authenticates the document, checking security features, the machine-readable zone, and barcodes, extracts the information printed on it, and compares the photo on the document against the submitted selfie. It is suitable for onboarding flows that confirm a government-issued document is genuine and belongs to the user, without an ID authority lookup.

Enhanced Document Verification extends Document Verification with an additional check against the document issuer's records. It authenticates the document, compares the photo on the document against the submitted selfie, and cross-references the document data against the issuing authority's database in a single call. It is available where Smile ID is integrated with the document's issuing authority.

Biometric KYC verifies an individual's identity by combining a government ID authority lookup with biometric face matching. Smile ID validates the ID against the issuing authority's records, retrieves the registered photo on file, and performs a face comparison between the selfie and the official photo. It is suitable for confirming that an ID number is valid and that the person submitting it is the individual on record with the ID authority.

Enhanced KYC verifies an individual's identity by querying government ID authority databases in real time. Smile ID validates the ID against the issuing authority's records and returns the personal information on file. It is suitable for confirming an ID number and retrieving the identity information associated with it, without biometric capture.
