Smile ID is the reference app for the Smile ID mobile SDKs. It runs the same verification flows a Smile ID integration ships, so each product can be seen end to end before any code is written.

Verification runs use the Smile ID sandbox unless a linked session token specifies another environment.

Each product runs end to end: the SDK's own capture screens, where that product uses them, and the verification result it returns. What each product checks, and the identity documents and countries it covers, is documented at docs.smileidentity.com.

IN THIS APP

• Each product's capture flow, as the SDK presents it
• The outcome of every run, with its status, result code and job ID
• A history of previous runs, kept on the device
• Light and dark themes, and the SDK's theming options

Smile ID provides digital KYC, identity verification and onboarding across Africa.
